# Saikou Diallo portfolio

Personal portfolio for Saikou Diallo, a computer science student at Nordakademie in Germany.

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

Pushes to `master` deploy through GitHub Actions to GitHub Pages.

Live site: https://dsaikou618.github.io/portfolio/

## Structure

- `index.html`
- `styles.css`
- `favicon.svg`
- `fonts/`
- `DESIGN.md` (local design reference, not deployed)
